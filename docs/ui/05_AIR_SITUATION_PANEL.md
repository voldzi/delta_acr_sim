# Air situation panel

**Status:** Baseline dokumentace

## Účel

Panel zobrazuje souhrn syntetických aircraft, UAV a missile-track objektů pro kontrolu scénáře. Není NATO renderer hlavní COP aplikace.

## Zobrazení

- počty objektů podle bloku
- stav tracků
- confidence/accuracy agregace
- lost/restored události
- synthetic marker
- event rate

## Omezení

Panel nesmí poskytovat taktická doporučení, targeting nebo navádění.
