# UI design principles

**Status:** Baseline dokumentace

## Charakter UI

SIM UI je pracovní nástroj pro technické uživatele. Má být přehledné, husté, klidné a orientované na stav, validaci a rychlé řízení scénářů.

## Principy

- jasný runtime state
- viditelné syntetické označení
- oddělení draft/edit/run stavu
- bezpečné potvrzení rizikových akcí
- auditní stopa u AI a publisher změn
- rychlé filtrování a skenování eventů
- žádné marketingové nebo dekorativní obrazovky
