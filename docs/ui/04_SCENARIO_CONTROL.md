# Scenario control UI

**Status:** Baseline dokumentace

## Ovládání

- start
- pause
- resume
- stop
- reset
- step
- dry-run toggle podle oprávnění

## Stavy

Control panel zobrazuje `DRAFT`, `READY`, `RUNNING`, `PAUSED`, `STOPPED`, `ERROR` a vysvětluje blokující validace bez dlouhého textu.

## Bezpečné akce

Stop runtime a stop publishing jsou oddělené akce s jasným důsledkem.
