# Report simulator

**Status:** Baseline dokumentace

## Účel

Generuje manuální textová hlášení pro test ingestu, auditních toků a zobrazení reportů.

## Data

- report ID
- synthetic author/source label
- timestamp
- location optional
- text
- classification with SYNTHETIC
- confidence

## Pravidla textu

Texty musí být zjevně syntetické, nesmí obsahovat osobní údaje, secrets, targeting nebo instrukce k reálné operaci.
