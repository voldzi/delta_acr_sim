# Rescue simulator

**Status:** Baseline dokumentace

## Účel

Generuje syntetické rescue a crisis incidenty pro test nevojenských situačních dat.

## Data

- incident ID
- incident type
- severity
- location
- status
- reportedAt
- assigned synthetic rescue asset
- confidence

## Scénáře

- incident created
- incident updated
- asset movement
- status resolved
- conflicting report for validation test

## Omezení

Incidenty jsou laboratorní a nesmí obsahovat reálné osobní údaje nebo operační data.
