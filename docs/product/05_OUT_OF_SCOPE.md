# Mimo rozsah

**Status:** Baseline dokumentace

## Zakázané domény

- Reálné bojové plánování a taktická doporučení.
- Targeting, prioritizace cílů, navádění a zbraňové workflow.
- Modelování účinnosti zbraní nebo optimalizace útoku.
- Vyhýbání detekci nebo postupy proti protivníkovi.
- Napojení na reálné operační zdroje bez explicitního nového bezpečnostního zadání.

## Technicky mimo tento baseline

- Produkční frontend, backend a simulační engine.
- Docker Compose implementace.
- Reálné AI API volání a správa API klíčů.
- Plná testovací sada; tento krok definuje pouze strategii a kontrakty.
