# Local development runbook

**Status:** Baseline dokumentace

## Účel

Popisuje budoucí lokální spuštění SIM aplikace. V tomto baseline ještě neexistuje produkční kód.

## Budoucí kroky

- nainstalovat Node/pnpm podle zvoleného stacku
- spustit API a web
- nastavit dry-run jako default
- použít mock AI provider
- spustit contract testy proti mock COP

## Bezpečnost

Lokální vývoj nesmí vyžadovat reálné COP credentials ani externí AI klíč.
