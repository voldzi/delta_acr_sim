# Prompt templates

**Status:** Baseline dokumentace

## Účel šablon

Prompt templates standardizují vstupy pro AI Scenario Assistant a snižují riziko nevalidního nebo nebezpečného výstupu.

## Základní šablona

Vstup musí obsahovat účel scénáře, povolené bloky, limity objektů, limit délky, oblast, provider režim a explicitní požadavek na syntetická data.

## Zakázané prvky

Šablony nesmí obsahovat instrukce k reálné taktice, targeting, navádění, použití síly nebo obcházení guardrails.
