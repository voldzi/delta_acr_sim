# Codex usage

**Status:** Baseline dokumentace

## Účel

Codex se používá pro vývojářské úlohy: generování skeletonů, testů, dokumentace a refaktorů. V runtime SIM systému může být reprezentován jako samostatný provider pouze pro podporované workflow, pokud to cílové prostředí umožní.

## Povolené použití

- návrh JSON scénáře
- validace konzistence
- generování dokumentace scénáře
- návrh testů a fixture dat
- vysvětlení chyb validace

## Omezení

Codex nesmí být používán k reálnému operačnímu plánování, targeting nebo navádění. Každý návrh zůstává draft a vyžaduje review.
