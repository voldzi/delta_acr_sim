Server-to-server provider

CSM SIM

SIM is a data-provider service for the COP backend. Browser clients and mobile clients must use COP APIs; SIM provider endpoints are intentionally not public UI APIs.

Public access is limited to this provider notice and /health/live. Catalog, feature, scenario and diagnostics endpoints are available only from internal networks, VPN, or explicitly allowed COP backend hosts.

  • GET /health/live public liveness probe
  • GET /situation-data/api/v1/catalog COP backend only
  • GET /situation-data/api/v1/features COP backend only
  • GET /flight-data/api/v1/catalog COP backend only
  • GET /safety-data/api/v1/catalog COP backend only
  • GET /docs/sim-bts-live-openapi.json BTS live status feed proposal
